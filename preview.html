ŠkolníWeby - Preview

Projekt je připraven!

Web je vytvořen pomocí Astro + Tailwind CSS. Pro plné spuštění potřebujete Node.js a npm.

Stránky:

  • / - Homepage
  • /ukazky - Ukázky webů
  • /cenik - Ceník
  • /jak-to-probiha - Proces
  • /kontakt - Kontakt

Jak spustit:

  1. Nainstalujte Node.js z nodejs.org
  2. Spusťte: npm install
  3. Spusťte: npm run dev
  4. Otevřete: http://localhost:8000

Struktura projektu:

src/
├── components/    # Komponenty (Navbar, Footer, Hero, atd.)
├── data/          # content.ts - zde upravujte obsah
├── layouts/       # BaseLayout.astro
├── pages/         # Všechny stránky
└── styles/        # Globální CSS
